# 1. Objetivos da Avaliação (GQM)

A avaliação da qualidade da extensão web do **VLibras** foi estruturada utilizando a abordagem *Goal-Question-Metric* (GQM) alinhada ao modelo da norma **ISO/IEC 25010:2023**. 

Abaixo estão definidos os objetivos de avaliação para cada característica selecionada no escopo.

---

## 1.1. Capacidade de Interação

| Elemento GQM | Descrição |
| :--- | :--- |
| **Analisar** | O widget da suíte VLibras |
| **Para o propósito de** | Avaliar e melhorar a autonomia de navegação e a clareza de feedbacks visuais |
| **Com respeito a** | Operabilidade, acessibilidade (contraste) e proteção contra erros |
| **Do ponto de vista do(a)** | Usuário final surdo e da equipe de avaliação de qualidade |
| **No contexto de** | Navegadores web (*desktop* e dispositivos móveis) em monitores de computadores e telas sensíveis ao toque (*touchscreen*) |

---

## 1.2. Eficiência de Desempenho

| Elemento GQM | Descrição |
| :--- | :--- |
| **Analisar** | O widget da suíte VLibras |
| **Para o propósito de** | Otimizar a velocidade de tradução e reduzir o consumo de recursos operacionais |
| **Com respeito a** | Comportamento temporal e utilização de processamento, memória e rede |
| **Do ponto de vista do(a)** | Usuário final e da equipe de desenvolvimento |
| **No contexto de** | Dispositivos com hardware modesto (CPU/RAM limitadas) e conexões de rede móvel restritas (3G/4G) |

---

## 1.3. Flexibilidade

| Elemento GQM | Descrição |
| :--- | :--- |
| **Analisar** | O widget da suíte VLibras |
| **Para o propósito de** | Reduzir a necessidade de adaptações manuais de código na integração |
| **Com respeito a** | Adaptabilidade a diferentes plataformas e instalabilidade em sistemas web |
| **Do ponto de vista do(a)** | Desenvolvedor responsável pela integração e usuário final |
| **No contexto de** | Diferentes sistemas operacionais (Windows, Linux, Android, iOS) e múltiplos navegadores web (Chrome, Firefox, Edge, Safari) |

---

## 1.4. Manutenibilidade

| Elemento GQM | Descrição |
| :--- | :--- |
| **Analisar** | O código-fonte e os componentes de interface do widget VLibras |
| **Para o propósito de** | Aumentar o reuso de componentes e facilitar a correção de falhas no repositório |
| **Com respeito a** |Manutenibilidade com foco na modularidade, reusabilidade e modificabilidade na construção da ferramenta |
| **Do ponto de vista do(a)** | Equipe de desenvolvimento e manutenção do software |
| **No contexto de** | Ambiente de desenvolvimento (repositório Git/GitHub) e ferramentas de compilação/*build* do projeto |
