# Dados brutos da ME3.1

As duas coletas estão separadas para distinguir o resultado obtido pelo protocolo da Fase 3 do teste complementar em um portal real.

| Coleta | Registro detalhado | Arquivos preservados |
| ------ | ------------------ | -------------------- |
| Padronizada | [Resultado da coleta](./padronizado/resultado.md) | HAR, CSV classificado, script de cálculo e 39 capturas de tela. |
| Complementar no gov.br | [Resultado da coleta](./govbr/resultado.md) | HAR, CSV classificado, script de cálculo e 27 capturas de tela. |

O teste no gov.br é complementar e não substitui o resultado da coleta padronizada.
