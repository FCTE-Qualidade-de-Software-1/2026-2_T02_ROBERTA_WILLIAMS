# Dados brutos da Fase 4

Os registros desta pasta preservam os arquivos usados para calcular e interpretar as métricas. Os materiais estão agrupados por identificador da métrica; coletas diferentes da mesma métrica ficam em subpastas próprias.

| Métrica                    | Conteúdo                                                                                                                         |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| [ME1.1](./ME1.1/README.md) | Instantes e tempos de resposta por frase e perfil, estatísticas e gravações de tela.                                             |
| [ME2.1](./ME2.1/README.md) | CSVs de uso de CPU por segundo das 5 sessões, script de coleta e capturas da saída do script e da configuração do processador.   |
| [ME3.1](./ME3.1/README.md) | Coleta padronizada na página de teste e coleta complementar no portal gov.br: HARs, CSVs, scripts, registros e capturas de tela. |
| [MI2.1](./MI2.1/README.md) | Tabela com mensagens de erro/status observadas, classificação visual, cálculo e capturas de evidência. |
| [MM1.1](./MM1.1/README.md) | Inventário da análise estática e capturas de evidência do Design System.                                                         |
| [MM2.1](./MM2.1/README.md) | Script e arquivo gerados na análise das alterações por commit.                                                                   |
| [MM3.1](./MM3.1/README.md) | Tabela compartilhada com dados brutos, prints e json das issues.                                                                  |
| [MF1.1](./MF1.1/README.md) | Matriz CSV dos cinco ambientes, vídeos no YouTube e planilha publicada dos cálculos. |
| [MF2.1](./MF2.1/README.md) | Prints das três etapas (sem o widget do portal, injeção e tradução) nos 10 portais da amostra. |

Quando novas métricas forem coletadas, seus dados devem ser adicionados em uma pasta com o identificador correspondente, preservando arquivos brutos, planilhas, scripts e evidências.
