# Dados brutos da MM3.1

| Arquivo/pasta                              | Conteúdo                                                                                                                                              |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Tabela de medições](../../manutenibilidade/mm3-1/medicoes.md) | Classificação das *issues* (incluída ou excluída, com o motivo), datas de abertura e de fechamento, dias de cada uma e estatísticas (média, mediana e médias por estado). |
| `prints/`                                  | Captura da lista de *issues* do repositório na data da coleta (`issues.png`), usada como evidência na página de resultado.                           |
| `issues.json`                              | Exportação de todas as issues do repositório `spbgovbr-vlibras/vlibras-web-browsers`, com número, título, estado, data de abertura e data de fechamento de cada *issue*. |

A coleta foi feita em 21/11/2026, e essa é a data usada como fim das *issues* abertas. A classificação das *issues* foi feita manualmente pelo critério do método de avaliação, e a tabela de medições permite conferir cada decisão. O resultado e suas limitações estão em [MM3.1 - Tempo médio de correção de incompatibilidades](../../manutenibilidade/mm3-1/mm3-1-tempo-medio-de-correcao-de-incompatibilidades.md).
